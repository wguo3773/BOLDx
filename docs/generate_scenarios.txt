Generate ordered toxicity scenarios from adjacent-dose gaps

Description:

     Generate a reproducible panel for one MTD category and gap
     combination. This is a defined uniform-tail generator, not a claim
     to sample all possible dose-toxicity curves or to reproduce
     previously saved manuscript scenarios.

Usage:

     generate_scenarios(
       ndoses = 4L,
       target = 0.25,
       mtd = 2L,
       lower_gap = 0.1,
       upper_gap = 0.15,
       risk_bounds = c(0.01, 0.7),
       nscenarios = 50L,
       seed = 1L
     )
     
Arguments:

  ndoses: Number of dose levels, 2 to 10; default 4.

  target: Target untreated DLT probability; default 0.25.

     mtd: MTD category. For 1:ndoses, fix that dose at target. Zero
          means all too toxic; ndoses+1 means all doses below target.
          Default 2.

lower_gap, upper_gap: Positive adjacent-dose risk gaps, default 0.10
          and 0.15. For an interior MTD j, set p[j-1]=target-lower_gap
          and p[j+1]=target+upper_gap when those neighbors exist.

risk_bounds: Lower and upper limits for generated risks, default
          c(0.01,0.70). Must lie strictly inside (0,1) and contain
          target.

nscenarios: Number of scenarios for this category and gap setting,
          default 50.

    seed: Nonnegative integer seed; the caller's random state is
          restored.

Details:

     Remaining lower doses are sorted uniform draws between the lower
     risk bound and the fixed lower neighbor; remaining upper doses are
     sorted uniform draws between the fixed upper neighbor and upper
     bound. For mtd=0, the first risk is target+upper_gap and remaining
     risks are uniform draws above it. For mtd=ndoses+1, the last risk
     is target-lower_gap and remaining risks are uniform draws below
     it. Gaps requiring a neighbor must leave a nonempty interval
     inside risk_bounds. Some boundary settings have no free doses and
     produce identical curves; inspect the matrix.

Value:

     Numeric matrix of true risk vectors, one scenario per row.

Examples:

     generate_scenarios(nscenarios=3, mtd=2, upper_gap=.15, seed=42)
