Simulate BOLD extensions and matched comparators

Description:

     Evaluate dose-finding accuracy, enrollment, actual toxicity,
     allocation above the MTD, and calendar duration for BOLD
     extensions and their comparators.

Usage:

     simulate_bold(
       truth = NULL,
       method = c("prediction", "tite", "combined"),
       config = bold_config(),
       nsim = 1000L,
       seed = 1L,
       mtd = NULL,
       p.true = NULL
     )
     
Arguments:

   truth: Nondecreasing vector of 2 to 10 untreated DLT probabilities,
          strictly between zero and one.

  method: One or more of prediction, tite, combined, bold, boin,
          tite_boin.

  config: A configuration from bold_config().

    nsim: Number of replicate trials per method, default 1000.

    seed: Nonnegative integer seed. The caller's random state is
          restored.

     mtd: True optimal dose index for evaluation. NULL chooses the dose
          closest to target (lower index breaks ties). Set 0 for
          all-too-toxic; K+1 means all doses are below target and the
          highest dose is optimal. This value affects summaries only,
          never dose decisions.

  p.true: Alias for truth, for a user-specified dose-toxicity scenario.
          Supply one name, or identical values under both names.

Details:

     Fixed cohorts of three are used. Intervention failure is an
     observed DLT, not an extra latent branch. In combined mode,
     intervention follow-up resolves before the next dose decision.
     Mixture weights use sequential child-specific plug-in scores; the
     full calculation and assumptions are documented in the package's
     online Methods document.

Value:

     A bold_simulation list containing summary, trials, config, truth,
     mtd, and seed. Summary contains scenario-level point estimates.
     Optional Monte Carlo precision diagnostics are retained separately
     in mcse.

Uncertainty:

     For one fixed scenario, mcse reports Monte Carlo standard errors
     across the nsim trials, not between-scenario SD. Accuracy SE is
     100 times the sample SD of trial-level correct-selection
     indicators divided by sqrt(nsim). For mean N, actual DLTs and
     duration, SE is the trial-level sample SD divided by sqrt(nsim).
     Above-MTD SE uses the influence values of the patient-weighted
     ratio, not an unweighted mean of trial ratios.  Raw trial records
     are retained in trials for other summaries.

Examples:

     z <- simulate_bold(c(.10, .25, .45, .60),
       method = c("prediction", "bold", "boin"), nsim = 10, seed = 1)
     z$summary
